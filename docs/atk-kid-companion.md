# “小芽”儿童成长伙伴使用与隐私指南

## 现在能做什么

小芽是面向即将入学儿童的语音成长伙伴。当前固件优先验证一条可靠闭环：孩子用语音提出需求，模型调用板载工具，设备用物理按键和本机约束守住安全边界。适合讲故事、知识问答、分步提示和简短鼓励；不做体感游戏，也不替孩子完成作业。

可直接对小芽说：

- “这里光线怎么样？”——读取 AP3216C 的粗粒度状态。
- “记住我喜欢恐龙。”、“忘掉恐龙。”——写入或删除本机有限记忆。
- “开始配网”或“重新配网”——无需先说“你好小智”；设备在本机识别后直接启动本地热点，不调用云端模型。
- “帮我拍一下这幅画。”——小芽提示按 KEY2；按下后 20 秒内说“拍吧”，模型才可取一帧。

自由语音识别和回答仍依赖当前小智服务；“你好小智”在本机识别，但后续对话需要网络。固定词“开始配网”和“重新配网”由 ESP32-S3 上的中文 MultiNet Q8 完全离线识别，命中后写入一次性启动标记并重启进入本地热点，不经过 MQTT、MCP 或云端模型，也不清除已有 Wi-Fi。首次启动、找不到已保存网络或连接超时会自动进入同一热点；手机连接屏幕显示的 Xiaozhi 热点并打开本地地址即可配置。启动阶段也可按 BOOT 进入该本地门户。当前版本不宣称支持离线自由对话。

传感器不可用时，环境工具会返回 `unknown` 或 `null`，小芽必须直接说明暂时无法判断，不得把默认值当作真实环境读数。

## 按键

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| BOOT | 开始/停止对话；启动阶段进入本地配网 | — |
| KEY0 | 音量 +10%，最高 70% | 设为 70% |
| KEY1 | 音量 -10% | 静音 |
| KEY2 | 在有效的语音拍照请求后，授权一张照片并开始监听 | — |
| KEY3 | 停止/取消并撤销拍照授权 | 请求清除本机成长记忆；10 秒内按 KEY2 确认 |

新设备音量默认 45%。已保存的较低音量会保留，任何按键或 AI 工具调用都不能越过 70% 板级上限。

## 拍照隐私边界

1. 孩子明确用语音提出拍照请求后，模型先调用 `self.camera.request_photo`；这只创建一条 60 秒有效的待确认请求，不取帧、不上传。
2. 没有这条语音请求时，KEY2 不会授权；即使模型误调用 `self.camera.take_photo`，固件也会拒绝。
3. 有效请求后的 KEY2 创建一次、20 秒有效的物理授权；KEY3、超时或重启会撤销请求和授权。
4. 若 QMA6100P 判断设备仍在移动，本次拍照被拒绝，但未过期授权仍保留。
5. 成功取帧立即消费授权；并发的第二个取帧会被门闩拒绝。固件只为本次图片解释复制并上传一帧。
6. 图片解释无论成功或失败，PSRAM 帧都会被清零并释放；不写入 TF 卡、Flash 或成长记忆。

本固件不持续保存图片，也不实现人脸识别。图片解释服务的网络侧留存策略属于服务端边界，应单独核对，不能由设备固件保证。

## 本机成长记忆

NVS 只允许以下内容：

- 一个昵称；
- 最多 5 个兴趣；
- 最多 20 个已学主题；
- `温和`、`简短`、`挑战式` 三种鼓励偏好之一。

固件会限制长度、去重并拒绝明显包含学校、住址、联系方式、秘密、照片、账户或密码的信息。语音删除调用可以删除单项、某一类或全部内容；KEY3 长按加 KEY2 是不依赖云端工具调用的一键清空路径。

这些是设备 NVS 中的受控字段，不等于小智云端会话记忆。若控制台提供广泛长期记忆开关，儿童设备应关闭；实际云端留存仍以所用服务的设置和政策为准。

## 小智控制台角色提示词

将下面内容粘贴到设备角色提示词中：

```text
你叫“小芽”，是一个原创的中性幻想萌兽，也是即将上小学孩子的成长伙伴。你说普通话，语气温暖、自然、有好奇心；每次尽量用 1 到 3 个短句，一次只讲一个重点。

你可以讲适龄故事、回答知识问题、陪孩子做小测验，也可以给学习提示。遇到作业或题目时，不直接给最终答案或代写：先问孩子已经怎么想，再给一步提示，等孩子回应后再给下一步，最后用一句话解释原理。孩子答错时不嘲笑、不制造焦虑。

合理使用设备工具：询问光线、手是否靠近或设备是否放稳时调用 self.sensors.get_environment；需要个性化鼓励前可调用 self.child_profile.get。只有孩子或家长明确要求“记住”时才调用 self.child_profile.remember，明确要求删除时调用 self.child_profile.forget。不要主动扩大记忆范围。

拍照必须遵守语音请求和物理确认：孩子明确用语音提出拍照后，先调用 self.camera.request_photo 登记本次请求，再说明“请按 KEY2，听到提示后再说拍吧”。只有孩子按键并再次说“拍吧”后才调用 self.camera.take_photo；移动拒拍时请孩子放稳后重说“拍吧”。不要跳过 request_photo，不要索取、记忆或推断人脸身份。

用户说固定词“开始配网”或“重新配网”时，固件会在本机直接处理，你不需要也不应再次调用工具。只有用户使用其他自然语言在线提出配网需求时，才先明确询问是否现在进入本地配网；得到肯定回答后调用 self.system.reconfigure_wifi，并把 confirmed 设为 true。随后指导连接屏幕上的 Xiaozhi 热点并打开本地地址。

绝不索取或记忆学校、住址、联系方式、秘密、照片、账户、密码或支付信息，不诱导孩子隐瞒家长。遇到危险、医疗、欺凌、陌生人联络或让孩子害怕的内容，先给简短安全建议，并请孩子马上找可信任的成年人。不要声称自己是真人、老师或医生。
```

角色名后续可通过板级 `config.h` 中唯一的 `KID_COMPANION_NAME` 修改；控制台提示词中的显示名应同步修改。

## 暂不实现

- Live2D、数字人视频、真正口型同步；
- 体感游戏、活动量统计、跌倒或“儿童在场”判断；
- 自动明暗主题、近手自动唤醒、拿起/放下表演；
- TF 卡持久化、照片归档、广泛人物画像；
- 离线自由对话。

这些边界让当前版本先证明角色、语音工具、离线配网、有限记忆与一次性拍照授权能在 ESP32-S3 上稳定协作。
